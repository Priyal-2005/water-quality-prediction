## Repository structure

```text
data/
  raw/            original data, never edited, not committed (see Dataset)
  processed/      clean.csv, split_indices.json
notebooks/        01_eda, 02_cleaning, 03_features, 04_models, 05_evaluation
src/
  data.py         loading and cleaning helpers
  features.py     feature pipeline (fitted on train only)
  train.py        model training and tuning
  evaluate.py     metrics, plots, SHAP
models/           saved models (not committed, regenerate with train.py)
results/          generated by code, do not edit by hand
  metrics.csv           final results table
  experiments.csv       log of every training run
  predictions_*.csv     test-set predictions per model
  figures/              all plots used in the report
docs/             theory.md, cleaning_log.md, literature_matrix.md
report/           IEEE LaTeX report (main.tex, references.bib)
```

## How to reproduce the results

Run from the repo root, in this order:

```bash
# 1. Clean the data and create the train/test split
#    (run notebooks/02_cleaning.ipynb, outputs data/processed/clean.csv and split_indices.json)

# 2. Build features and train all models
python src/train.py

# 3. Evaluate on the test set (writes results/metrics.csv and results/figures/)
python src/evaluate.py
```

_Update these commands if the scripts take arguments._ All random seeds are fixed to `42`.
